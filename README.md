
Site Vitrine - Centre ISAG

Site vitrine du centre ISAG : une plateforme web pour communiquer avec les étudiants et les visiteurs, et présenter les formations, les actualités et les services du centre. Son objectif est de rapprocher l'information des futurs étudiants et de faciliter la communication avec le centre.

Projet réalisé en équipe. Le backend Laravel est ici : backend_Site_Vitrine

Fonctionnalités
Pages principales : Accueil, À propos du centre, Formations disponibles, Contact
Navigation et mise en page : design organisé et responsive (ordinateur et téléphone), composants réutilisables, navigation simple
Chatbot IA (Botpress) : assistant configuré avec une base de connaissances, qui répond aux questions des visiteurs en temps réel, y compris en darija
Technologies

Frontend

React.js (application monopage - SPA)
Tailwind CSS / CSS
Axios / Fetch pour les appels à l'API
Lucide Icons / React Icons

Backend et intégration

PHP / Laravel pour les routes et la logique serveur
Botpress pour le chatbot
Git et GitHub pour le versionnement et le travail en équipe
Vercel pour le déploiement
Installation
bash
git clone https://github.com/soukainaaferdi/Site_Vitrine.git
cd Site_Vitrine
